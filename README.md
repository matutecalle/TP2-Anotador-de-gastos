# Anotador de gastos diarios — TP2 Desarrollo de Aplicaciones Móviles

MVP nativo para Android (Kotlin + Jetpack Compose) desarrollado aplicando el ciclo Build-Measure-Learn.

Permite registrar gastos con descripción, monto y categoría, verlos en una lista y consultar el total del día, todo en una sola pantalla y sin conexión a internet.

**Alumno:** Matías Callejo — UTN FRSF, Ingeniería en Sistemas de Información.

## Cómo ejecutarlo
Abrir la carpeta en Android Studio y correr la configuración `app` en un emulador o dispositivo.
